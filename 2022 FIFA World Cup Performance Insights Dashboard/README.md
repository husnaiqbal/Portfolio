
**2022 FIFA World Cup Performance Insights Dashboard**

This interactive dashboard was built to analyze and visualize key performance metrics from the 2022 FIFA World Cup. The project combines data exploration, visual storytelling, and user input to help those interested explore trends across teams and matches.


**Key Features:**

- **Total Goals Analysis:** Aggregated goals by team with bar graphs and choropleth maps
- **Succeeded Attempts:** Calculates shooting efficiency based on total attempts
- **Choropleth Map:** Visualizes goal distribution by country using ISO codes
- **Team Match Comparisons:** Choose any two teams to compare their performance in specific stats (e.g., possession, penalties, fouls)
- **Timeline Graphs:** Track match results over time (win/lose/draw)
- **Team-Specific Insights:** See a list of all matches for a specific team, color-coded by outcome

**Tools Used:**

- Python (pandas, plotly, Dash)
- Data Cleaning, Transformation, and Aggregation
- Custom Styling and Layout for Visual Appeal
